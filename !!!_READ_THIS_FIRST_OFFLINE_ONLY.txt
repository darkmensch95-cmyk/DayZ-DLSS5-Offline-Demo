======================================================================
INSTALLATION LOCATION - IMPORTANT
======================================================================

The downloaded GitHub ZIP/source folder may be extracted anywhere, for example:

    Desktop
    Downloads

That downloaded folder is only the installer/source package.

Run:

    INSTALL.cmd

from the extracted GitHub folder.

The installer creates the ACTUAL working installation at:

    C:\DayZ_DLSS5_OFFLINE_DEMO

After installation, start the offline demo from:

    C:\DayZ_DLSS5_OFFLINE_DEMO\START_OFFLINE_DEMO.cmd

DO NOT keep launching START_OFFLINE_DEMO.cmd from the downloaded GitHub source
folder after installation. The installed C:\DayZ_DLSS5_OFFLINE_DEMO folder
contains the generated config.json, downloaded payload, LocalHost files, logs
and runtime state required by the launcher.

The project is NOT permanently installed inside the normal DayZ game folder.
The known ReShade/DLSS5 payload is staged there only while the offline demo is
active and is removed again during cleanup.
