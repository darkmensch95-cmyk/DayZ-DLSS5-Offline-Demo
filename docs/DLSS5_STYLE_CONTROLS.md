# DLSS 5 Neural Rendering style controls

When the RenoDX/DLSS5 add-on loads correctly, ReShade gets an **extra RenoDX/DLSS5 settings tab at the top of the overlay**. This is added by the installed add-on; it is not one of ReShade's normal default tabs.

Open the ReShade overlay with `Home`, then open that extra DLSS5/RenoDX tab. The Neural Rendering settings include an **NR Style** selector with:

- `Default`
- `Natural`
- `Cinematic`

These styles can be switched live while the local DayZDiag demo is running, which makes it useful for direct screenshots/video comparisons without changing the main feeder preset.

The shipped beta7 setup already brings up DLSS 5 with the included preset on the reference machine, so changing NR Style is optional rather than a required setup step.

> **Offline/local DayZDiag only:** this UI note does not change the project's BattlEye warning. Do not use the staged demo payload with normal DayZ/BattlEye or online servers.
